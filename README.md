# Vasool

An interactive 10-slide deck for a UX design challenge. Vasool is a mobile app concept that helps people use the perks inside memberships they already pay for.

- Use the arrow keys to move between slides. Press **N** for speaker notes.
- Slide 8 has a working prototype of the critical flow: perk nudge → perk card → confirm → reward → badge.
- Add `#8` to the URL to open the prototype slide, or `#prototype` to open only the phone, full screen.
